# 제로블루투스클리너

갤럭시에 등록된 블루투스 기기에서 계속 쓸 기기는 잠그고, 정리할 기기는 한꺼번에 등록 해제하세요.

**[⬇ 정식 1.0.0 APK 다운로드](https://github.com/ZERO-hms/zero-bluetooth-cleaner/releases/download/v1.0.0/zero-bluetooth-cleaner-1.0.0.apk)** · [설치 안내](#설치-안내) · [릴리스 정보](https://github.com/ZERO-hms/zero-bluetooth-cleaner/releases/tag/v1.0.0)

갤럭시 One UI 7.0 이상(Android 15 이상)에서 사용합니다. 설치 파일은 `zero-bluetooth-cleaner-1.0.0.apk`입니다.

## 설치 안내

1. 위 APK를 내려받아 엽니다. 갤럭시가 설치 허용을 요청하면 **설정 → 보안 및 개인정보 보호 → 기타 보안 설정 → 출처를 알 수 없는 앱 설치**에서 APK를 여는 앱(내 파일 또는 브라우저)을 선택하세요. ‘이 출처 허용’을 켜고 설치한 뒤 같은 화면에서 다시 끄세요.
2. 앱을 열고 **근처 기기** 권한을 허용하면 등록 목록이 보입니다. **알림**은 페어링 코드 입력과 선택한 업데이트 알림에 사용합니다. 기기를 등록 해제할 때는 첫 실행 안내 또는 앱 설정에서 무선 디버깅을 연결하세요.
3. **보안 위험 자동 차단**으로 막히면 공식 배포 파일인지 먼저 확인하세요. 설치를 선택한 경우에만 갤럭시 설정 → 보안 및 개인정보 보호 → 보안 위험 자동 차단을 일시 해제하고 설치 직후 다시 켜세요. 메뉴 이름은 기종과 One UI 버전에 따라 다릅니다. [삼성 안내](https://www.samsung.com/us/support/answer/ANS10003636/)
4. **Play 프로텍트**가 검사를 요청하면 검사하세요. 유해 앱 또는 기기 보호 차단이 표시되면 설치를 중단하고 파일과 버전을 확인한 뒤 저장소의 Issues로 문의하세요. 개발자가 오탐 검토를 요청할 수 있습니다. 회사·학교 기기의 설치 제한은 관리자에게 문의하세요. [Google 안내](https://support.google.com/googleplay/answer/2812853?hl=ko)

## 기기 정리

- **검색·정렬** — 이름 일부나 블루투스 주소 끝자리로 찾고, 최근 연결순·오래된 연결순·이름순으로 정렬하세요. ‘자세히’와 ‘간단히’로 목록 밀도를 바꿀 수 있습니다. 설치 전 연결 기록은 휴대전화가 제공하는 범위에서 가져오며, 순서만 제공하는 기기도 있습니다.
- **잠금** — 계속 쓸 기기의 자물쇠를 잠그면 전체 선택에서도 제외됩니다. 메인 화면의 새로고침 아이콘으로 현재 목록을 다시 읽습니다.
- **등록 해제** — 기기를 하나씩 선택하거나 검색 결과에서 전체 선택한 뒤 등록 해제할 이름과 주소를 확인하세요. 다시 쓸 때는 재페어링이 필요합니다. 설정에서 최근 정리 결과를 볼 수 있습니다.

## 무선 디버깅 연결과 종료

1. 휴대전화를 Wi-Fi에 연결하고 **앱 설정 → 무선 디버깅 설정**을 엽니다. 처음이면 ‘개발자 옵션 켜기’를 눌러 소프트웨어 정보에서 빌드번호를 7번 누른 뒤 개발자 옵션에서 무선 디버깅을 켜세요.
2. 앱에서 알림으로 페어링을 시작하고 시스템 설정에서 **페어링 코드로 기기 페어링**을 누르세요. 코드 창을 열어 둔 채 상단 팝업 알림의 **코드 입력**을 눌러 보이는 6자리를 보내세요. 배너가 보이지 않으면 앱의 팝업 표시 도움말을 확인하세요.
3. 재부팅이나 Wi-Fi 변경 뒤에는 **기존 연결로 다시 연결**을 누르세요. 앱의 연결 정보를 지우면 다음 연결 때 다시 페어링합니다.
4. 정리가 끝나면 **개발자 옵션 끄기**를 선택하세요. 개발자 옵션과 USB·무선 디버깅 종료를 요청하며, 앱에서 개발자 옵션 스위치가 꺼진 것을 확인하면 완료로 표시합니다.

## 업데이트

설정의 **앱 업데이트 → 지금 확인**에서 새 정식 버전을 확인하세요. 자동 알림을 켜면 새 정식 버전이 나왔을 때 알려줍니다. 업데이트 확인 시 기기 이름과 블루투스 주소는 전송하지 않습니다.

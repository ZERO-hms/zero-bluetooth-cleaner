**[⬇ 베타 4 APK 다운로드](https://github.com/ZERO-hms/zero-bluetooth-cleaner/releases/download/v0.5.0-beta.4/zero-bluetooth-cleaner-0.5.0-beta.4.apk)** · [설치 안내](#설치-안내) · [변경 사항](https://github.com/ZERO-hms/zero-bluetooth-cleaner/releases/tag/v0.5.0-beta.4)

갤럭시에 등록된 블루투스 기기가 많을 때, 계속 쓸 기기를 잠그고 나머지 기기의 페어링을 한 번에 해제할 수 있습니다. **갤럭시 One UI 7.0 이상(Android 15 이상)**을 대상으로 합니다.

## 설치 안내

1. 위 버튼으로 **zero-bluetooth-cleaner-0.5.0-beta.4.apk**를 받아 엽니다. 기존 베타 사용자는 앱을 지우지 않고 업데이트할 수 있습니다.
2. 설치 허용을 요청하면 갤럭시 **설정 → 보안 및 개인정보 보호 → 기타 보안 설정 → 출처를 알 수 없는 앱 설치**에서 APK를 여는 앱(예: 내 파일, Chrome)을 선택하고 **이 출처 허용**을 켭니다. 설치 후 같은 곳에서 다시 끄세요.
3. 앱을 열고 **근처 기기**를 허용하면 목록과 연결 기록을 볼 수 있습니다. **알림** 권한은 페어링 코드 입력과 새 버전 알림에 사용합니다. 업데이트 수동 확인은 알림을 꺼도 사용할 수 있습니다.
4. 기기 등록을 해제하려면 첫 실행 화면에서 **설정 안내 열기**를 눌러 무선 디버깅을 연결하세요. **나중에**를 눌러도 **⚙ 설정 → 무선 디버깅 설정**에서 같은 안내를 열 수 있습니다.

## 사용 방법

1. **찾기** — 블루투스를 켜고 기기 이름 일부나 주소 끝자리로 검색하세요. 최근 연결순·오래된순·이름순, 간단히·자세히 보기를 선택할 수 있습니다. 연결 시각이나 순서를 모르는 기기는 날짜 정렬에서 맨 아래에 나옵니다.
2. **보호하기** — 계속 쓸 기기 옆의 **해제**를 눌러 **잠김**으로 바꾸세요. 잠긴 기기는 전체 선택에서도 빠집니다.
3. **정리하기** — 기기를 개별 선택하거나 현재 검색 결과에서 **전체 선택**을 누르세요. **등록 해제**를 누른 뒤 이름과 주소를 확인합니다. 다시 사용하려면 재페어링해야 합니다. 처리 결과는 **⚙ 설정 → 최근 정리 결과**에서 확인하세요.

### 등록 해제용 무선 디버깅 연결

1. Wi-Fi에 연결하고 갤럭시 **설정 → 휴대전화 정보 → 소프트웨어 정보 → 빌드번호**를 7번 눌러 개발자 옵션을 켜세요. **개발자 옵션 → 무선 디버깅**을 켭니다.
2. **앱 ⚙ 설정 → 무선 디버깅 설정 → 알림으로 연결 시작**을 누르세요. 시스템 화면에서 **페어링 코드로 기기 페어링**을 선택한 뒤 앱 알림에 6자리 코드를 입력하세요.
3. 재부팅이나 Wi-Fi 변경으로 끊기면 **새 세션 재연결**을 누르세요. 자동 탐색이 어려울 때는 고급 메뉴에서 포트를 직접 입력할 수 있습니다. 연결을 해지하려면 앱의 연결 정보를 지우고 시스템의 무선 디버깅 페어링 목록에서도 BluetoothTidy를 삭제하세요.

무선 디버깅은 기기 등록 해제와 **휴대전화 연결 순서 가져오기**에 사용합니다. 일상적인 목록 조회·검색·잠금, 앱이 관찰한 연결 기록에는 근처 기기 권한만 필요합니다. 설치 전 기록은 휴대전화가 제공하는 범위에서 순서를 가져오며, 정확한 날짜를 알 수 없는 경우가 있습니다. 별도의 도우미 앱이나 접근성 서비스는 필요하지 않습니다.

## 업데이트 알림

**⚙ 설정 → 앱 업데이트 → 새 버전 자동 알림**을 켜세요. 기본값은 꺼짐입니다. 인터넷에 연결되면 약 6시간마다 공개 릴리스를 확인하고 새 버전당 한 번 알려줍니다. 절전 상태에 따라 시점이 달라질 수 있습니다. 바로 확인하려면 **지금 확인**을 누르세요. 새 버전 알림을 누르면 변경 사항과 APK 받기 버튼이 나옵니다. 업데이트를 확인할 때 블루투스 기기 이름이나 주소는 전송하지 않습니다.
